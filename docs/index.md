# 🌍 Earth Engine Agent

**Your AI-powered assistant for Google Earth Engine.**

Earth Agent integrates cutting-edge AI models (OpenAI, Anthropic, Gemini, Qwen, Ollama) directly into the Earth Engine Code Editor, helping you write, debug, and execute code faster than ever.
