## Single Purpose Description

## Permission Justifications

**sidePanel**
Required to display the AI chat interface alongside the Earth Engine Code Editor.

**storage**
Required to save user settings, API keys, and chat history locally.

**activeTab**
Required to interact with the Earth Engine Code Editor tab.

**tabs**
Required to detect and communicate with Earth Engine Code Editor tabs.

**scripting**
Required to inject content scripts that interact with the Earth Engine Code Editor DOM.

**downloads**
Required to allow users to export chat history and test results.

**identity**
Required for Google Drive integration (optional screenshot uploads).

**Host Permissions:**
- https://code.earthengine.google.com/* - Access Earth Engine Code Editor
- https://context7.com/* - Fetch Earth Engine documentation
- https://api.anthropic.com/* - Anthropic API for Claude models
- https://www.googleapis.com/upload/drive/v3/* - Google Drive uploads (optional)

Note: localhost permissions are NOT included in Web Store version for compliance.
