📋 USAGE INSTRUCTIONS FOR inspectMap TOOL

⚠️ IMPORTANT: inspectMap reads EXISTING Inspector data
It does NOT simulate clicks automatically.

USAGE WORKFLOW:
===============
1. Open Earth Engine Code Editor (https://code.earthengine.google.com)
2. Activate the Inspector tab (right side panel)
3. Manually click on the map at the location you want to inspect
4. THEN run inspectMap tool from the extension

WHAT IF INSPECTOR IS EMPTY:
============================
Error: "Inspector is empty. Please manually click on the map..."
Solution: Click on the map first, then run the tool again

WHAT IF COORDINATES DON'T MATCH:
=================================
Error: "Inspector shows data for coordinates (X, Y), which is different from requested..."
Solution: Click on the correct location on the map first
