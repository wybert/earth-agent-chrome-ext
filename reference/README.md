# Reference Documentation

This directory contains technical documentation, research notes, and configuration data for the Earth Agent project.

## Directories

- **api-models/**: JSON definitions and metadata for supported AI models (OpenAI, Anthropic, Gemini).
- **deploy/**: Guides for deployment, Chrome Web Store publishing, OAuth setup, and environment configuration.
- **implementation/**: Core technical documentation including system architecture and the developer guide.
- **notes/**: Detailed technical analysis, system design documents, research notes, and the Product Requirements Document (PRD).
- **samples/**: Sample prompts and example data used for testing and demonstrating Earth Engine capabilities.
- **testing/**: Documentation regarding testing procedures, feature analysis, and DOM inspection reports.
